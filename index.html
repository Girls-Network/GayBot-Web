GayBot brings keyword emoji reactions, identity profiles, an LGBTQIA+ term lookup, and a few fun extras to your community — built by queer people, for queer servers.

Add to Discord View on GitHub

Features

🪪
/identity
Save and share your pronouns, gender, sexuality, romantic orientation, and flag — all in one tidy profile.
📖
/lgbtqsearch
Look up any LGBTQIA+ term and pull a clear definition straight from girlsnetwork.dev — optionally pinging a friend.
✨
Keyword reactions
Auto-react with relevant emoji when keywords show up in chat. Configurable per-server, togglable per-user.
🌸
/yuri hug · kiss · boop
Soft yuri reaction GIFs for hugs, kisses, and boops. Browse the full library on the GIFs page.
🌈
/gaycounter
The objectively scientific™ measurement of how gay someone is. Strictly for laughs.
🧠
PluralKit & Plural support
First-class handling for plural systems — proxied messages route to the correct member's identity and prefs.
🛠️
Per-user & per-server controls
/user commands lets each member opt out individually. /admin commands lets server staff disable commands globally.
📡
Sharded & open source
Built on Discord.js v14 with sharding for scale. MIT-licensed source on GitHub.
